Here’s how it works.

A native Mac companion for talking about your screen and delegating browser work. Built for a hackathon, with you in control of the final action.

Make yourself at home.

You need an Apple silicon Mac with macOS 14 or later, internet access, and your own OpenAI API key. Browser tasks also need a compatible Codex CLI with app-server and dynamic-tool support. The configured models are gpt-live-1, gpt-5.6-luna, and gpt-5.6-sol; your account must have access. Usage is billed to your API account.

  1. Download and open. Get the app from the download section, unzip it, and move Computah.app to Applications. This prototype is not notarized. Follow normal macOS security controls; do not disable system protections.
  2. Bring your own API key. Click the character or chevron at the top of the display, open Settings, paste your OpenAI API key, and save it to macOS Keychain. There is no Dock icon or separate menu bar item.
  3. Allow access. Microphone enables voice; Screen Recording enables screen context; Input Monitoring enables the conversation key. Use the permission controls in settings. Reopen the app if macOS requests it.
  4. Check Codex. Computah checks its inherited PATH, then ~/.local/bin, /opt/homebrew/bin, /usr/local/bin, and ~/.cargo/bin for the CLI. A Finder launch does not inherit your shell’s PATH.
  5. Start talking. Tap Right Shift, or use Start talking. Hold the conversation key and drag to circle a region, then ask about it. Escape cancels the selection.

Try: “Find the official NUS Master of Computing General Track admissions requirements and summarize them with source links.” Open the task browser to watch. Choose Take over to stop the worker before interacting yourself.

One conversation.
Independent browser work.

We built three cooperating parts: a native companion, a voice session, and a browser workspace for each delegated task. The Mac runs the interface and local workers; the models run remotely.

  1. Talk and pointSwiftUI and AppKit host the notch panel. AVFoundation streams voice; ScreenCaptureKit captures the display and optional selected crop.
  2. Understand the requestA routing model chooses conversation, screen interpretation, browser work, or showing an existing browser. Vision returns text findings to the voice session.
  3. Work in a separate browserEach independent task gets a local Codex app-server process and a nonpersistent WebKit session. Six tools navigate, observe, click, type, scroll, and request review.
  4. Return to youResults appear in the task panel. Watching leaves work running. Taking over stops the worker and gives you manual control.

Separating task lifecycles lets you continue using your Mac while research runs. Ending voice leaves browser tasks running; quitting the app stops all workers. Sessions are not restored after relaunch.

Swift Package Manager builds the app without third-party package dependencies. Hosted Mac CI checks the Swift code and release tooling. Tagged releases package the app and static website together, with a manifest and SHA-256 checksum for the download.

Your context, with clear limits.

Microphone audio goes to OpenAI during conversation. Available display images and a selected crop can be sent for routing and interpretation. Circling does not restrict sharing to the crop. Browser observations also include page text and screenshots.

The API key lives in macOS Keychain. Each task uses a separate nonpersistent browser and temporary worker configuration, rather than your normal browser or Codex profile. Temporary files are removed on normal worker exit; abrupt failures can leave them behind. Requests set store: false, which is not a promise of zero retention under the provider’s policies.

During preparation, website JavaScript is disabled and form submissions, non-GET navigation, and recognized consequential controls are blocked. Modern portals may require manual takeover. Reloading after takeover enables website scripts and can clear prepared fields. Sign-in, uploads, and final submission stay with you.

These are prototype restrictions, not complete operating-system or network isolation. The app does not automate other desktop applications. Broad release still needs signing and notarization, wider hardware validation, and resource controls for long-running use.

Get back to the conversation.

The shortcut does nothing
Check Input Monitoring and the conversation-key setting. Start talking works without the shortcut.
The microphone or voice connection fails
Check input/output devices, the network, API key, and model access. Reopen the app and retry. Use headphones if the app reports that echo cancellation is unavailable.
A page will not load or a task stalls
Check Codex installation and the browser’s current page. Scripted websites can require Take over and a manual reload. Use Stop task to end work that is no longer useful.
