Read the setup guide
What does the prototype need?

An Apple silicon Mac running macOS 14 or later, internet access, and your own OpenAI API key with access to the configured models. API usage is billed to your OpenAI account. Browser work also needs a compatible Codex CLI installation.

Can it complete an entire application for me?

It can help with research and preparation. You provide your actual qualifications and experiences, check the official requirements, and handle sign-in, uploads, and submission yourself. Website JavaScript is disabled during preparation, so modern application portals may require you to take over before useful preparation is possible.

What can it see, and what is shared?

Microphone access enables conversation. Screen Recording allows display interpretation, and Input Monitoring enables the conversation shortcut. During conversation, available screenshots may be sent to OpenAI for routing and interpretation. A selected region can be sent alongside the full display; circling does not restrict sharing to the crop.

Your API key is stored in macOS Keychain. Task browsers use separate nonpersistent sessions instead of your usual browser profile.

Are the screenshots from a real application?

They are captured from Computah’s native interface using a reproducible local demo. The transcripts, institutions, and application details are illustrative. The demo exercises real browser tools and manual takeover, but does not run an authenticated model conversation or submit anything. Captures reflect the current development interface; the available ZIP remains version 0.1.0, build 6.
