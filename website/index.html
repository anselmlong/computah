Do I need my own API key, and what does it cost?

Bring your own OpenAI API key for voice and screen reading. OpenAI bills that API account. Computer tasks use your signed-in Codex account and its plan limits.

Voice is $0.05/minute, with Luna routing and vision charged separately. Illustrative API totals are $0.51 for a short 10-minute demo, $1.52 for a 30-minute session, and $3.04 for a heavier hour, before Codex usage. See rates, assumptions, and sources.

What does the prototype need?

An Apple silicon Mac running macOS 14 or later, internet access, and an OpenAI API key for voice and screen reading. Computer work also needs a compatible Codex CLI signed in to an account with the required native apps and plugins.

Can it book, send, or submit for me?

It helps with research and preparation. Its instructions require your explicit confirmation before payments, bookings, sending, and final submissions. Computah asks through the active voice conversation and returns your answer to that same task. The current YOLO-mode runtime does not enforce the instruction, so inspect task activity carefully. There is no direct email integration; you can ask about an email visible on your screen.

What can it see, and what is shared?

Microphone access enables conversation. Screen Recording allows display interpretation, and Input Monitoring enables the conversation shortcut. During conversation, available screenshots may be sent to OpenAI for routing and interpretation. A selected region can be sent alongside the full display; circling does not restrict sharing to the crop.

Your API key is stored in macOS Keychain and is not sent to Codex workers. Computer Use shares your existing applications, signed-in state, and desktop.

Are the screenshots from a real application?

They use native Computah views with illustrative transcripts, institutions, and application details. The browser images come from a reproducible legacy fixture, not the current native Computer Use runtime. The capture did not run an authenticated model conversation or submit anything.
